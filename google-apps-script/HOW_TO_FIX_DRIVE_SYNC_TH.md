# 🛠️ คู่มือแก้ไขปัญหา "เกิดข้อผิดพลาดในการเชื่อมต่อ Google Drive: Failed to fetch"

หากคุณพบข้อความแจ้งเตือนสีแดง:
> **"เกิดข้อผิดพลาดในการเชื่อมต่อ Google Drive: Failed to fetch"**
> และปุ่มสถานะด้านบนแสดง **"ไดรฟ์ออฟไลน์"** (จุดสีส้ม)

สาเหตุหลัก 99% เกิดจาก **การตั้งค่าสิทธิ์ (Permissions) ใน Google Apps Script** หรือ **การวาง URL ผิดรูปแบบ** 

---

## 🔍 สาเหตุที่แท้จริง
เมื่อหน้าเว็บส่งคำขอ (`fetch`) ไปยัง Google Apps Script:
1. หากใน Apps Script เลือก **"ผู้มีสิทธิ์เข้าถึง (Who has access)"** เป็น **"ฉันเท่านั้น (Only myself)"** หรือ **"เฉพาะในองค์กร"**
2. Google จะทำการ Redirect ผู้ใช้ไปยังหน้า Login ของ Google ทันที
3. เบราว์เซอร์จะบล็อกคำขอนี้ตามนโยบายความปลอดภัย **CORS (Cross-Origin Resource Sharing)** และแสดงผลใน JavaScript เป็น **`TypeError: Failed to fetch`**

---

## ✅ วิธีแก้ไขใน 4 ขั้นตอน (ใช้เวลาไม่เกิน 1 นาที)

### ขั้นตอนที่ 1: เปิด Google Apps Script
1. เข้าไปที่ [script.google.com](https://script.google.com) และเปิดโปรเจกต์ PAFolio ของคุณ
2. ตรวจสอบให้แน่ใจว่าได้คัดลอกโค้ดจากไฟล์ `google-apps-script/Code.gs` ไปวางเรียบร้อยแล้ว

### ขั้นตอนที่ 2: ทำการ Deploy ใหม่ (New Deployment)
1. มองไปที่มุมบนขวา คลิกปุ่มสีน้ำเงิน **"การทำให้ใช้งานได้" (Deploy)**
2. เลือก **"การทำให้ใช้งานได้ใหม่" (New deployment)**
3. ด้านซ้ายข้างคำว่า "เลือกประเภท" ให้คลิกไอคอนรูปเฟือง ⚙️ แล้วเลือก **"เว็บแอป" (Web app)**
4. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `PAFolio Live API`
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me)` *(อีเมลของคุณ)*
   - ⚠️ **ผู้มีสิทธิ์เข้าถึง (Who has access):** เลือก **`ทุกคน` (Anyone)** *(จุดนี้สำคัญที่สุด ห้ามเลือก "ฉันเท่านั้น")*
5. คลิกปุ่ม **"ทำให้ใช้งานได้" (Deploy)**

### ขั้นตอนที่ 3: ให้สิทธิ์เข้าถึง (Authorize)
1. หากมีหน้าต่างแจ้งเตือนให้สิทธิ์ ให้คลิก **"ให้สิทธิ์การเข้าถึง" (Review permissions)**
2. เลือกบัญชี Google ของคุณ
3. หากขึ้นหน้าต่างเตือนสีเทา "Google ยังไม่ได้ยืนยันแอปนี้":
   - คลิกคำว่า **"ขั้นสูง" (Advanced)** ที่มุมล่างซ้าย
   - คลิก **"ไปที่ ... (ไม่ปลอดภัย)" (Go to ... (unsafe))**
   - คลิก **"อนุญาต" (Allow)**

### ขั้นตอนที่ 4: คัดลอก URL เว็บแอปมาใส่ใน PAFolio
1. Google Apps Script จะแสดงหน้าต่างผลลัพธ์ ให้คัดลอก **"URL เว็บแอป" (Web App URL)**
   - *ตัวอย่าง URL ที่ถูกต้อง:* `https://script.google.com/macros/s/AKfycbx.../exec`
   - ⚠️ **ข้อควรระวัง:** URL ต้องลงท้ายด้วย `/exec` เท่านั้น (ห้ามใช้ URL จากช่องค้นหาของเบราว์เซอร์ที่ลงท้ายด้วย `/edit`)
2. กลับมาที่หน้าเว็บ **PAFolio**
3. คลิกที่ปุ่ม **"ไดรฟ์ออฟไลน์"** หรือ **"ตั้งค่า Google Drive"** ที่เมนูด้านบน
4. นำ URL มาวางในช่อง **"Google Apps Script Web App URL"**
5. คลิกปุ่ม **"⚡ ทดสอบการเชื่อมต่อ"**
   - หากขึ้นแถบสีเขียว *"เชื่อมต่อสำเร็จ 100%!"* ให้คลิก **"บันทึกและซิงก์ข้อมูล"** ได้ทันที!
